# AgentFlow Skills

Custom Hermes skills for AgentFlow agents (self-contained, no external services).

- **funnel-builder** — design a bot sales funnel as a message sequence + render an HTML flow diagram
- **bot-builder** — scaffold a runnable Telegram bot (python-telegram-bot)
- **publish** — publish a built site to a public https URL via the AgentFlow frp tunnel

Install: `hermes skills install lnlockly/agentflow-skills/skills/<name> --yes`
