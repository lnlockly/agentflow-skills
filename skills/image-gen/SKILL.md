# image-gen

## When to Use
Пользователь просит НАРИСОВАТЬ / СГЕНЕРИРОВАТЬ картинку, изображение, логотип,
иллюстрацию, арт, обложку, аватар по текстовому описанию. Триггеры: «нарисуй»,
«сгенерируй картинку/изображение», «сделай логотип/арт/обложку», «покажи как
выглядит …», «картинка …».

## Модель и доступ
- Модель: **`gpt-image-2`** (провайдер codex.sale). Доступна каждому агенту
  по умолчанию через его LLM-ключ — отдельно подключать НЕ нужно.
- Эндпоинт — тот же LLM-шлюз, что и для текста, но путь `/images/generations`:
  `$LLM_BASE_URL/images/generations` с заголовком `Authorization: Bearer $LLM_KEY`.
  (`LLM_BASE_URL` и `LLM_KEY` уже в окружении агента.)

## Железные правила
1. **Генерация ДОЛГАЯ — 30 сек…2 мин.** Сразу предупреди пользователя коротким
   сообщением («Рисую, это займёт минуту-две ⏳») и НЕ прерывай запрос по таймауту:
   ставь `curl -m 240` (или больше). Один запрос = одна картинка, ретраи НЕ нужны
   (каждый ретрай — новая платная генерация).
2. **Ответ — не URL, а base64.** Поле `data[0].b64_json` — это PNG в base64.
   Его надо декодировать в файл и ОТДАТЬ файлом, а не текстом.
3. **Отдача картинки** — положить готовый PNG в `/app/outbox/` (всё оттуда
   уходит пользователю автоматически). Имя файла — осмысленное, латиницей.
4. Каждая картинка платная (фиксированная цена). Не генери «на всякий случай» и
   не плоди варианты пачками без просьбы.

## Как сгенерировать (один вызов)
```bash
mkdir -p /app/outbox
curl -s -m 240 "$LLM_BASE_URL/images/generations" \
  -H "Authorization: Bearer $LLM_KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"ОПИСАНИЕ КАРТИНКИ на английском, детально","size":"1024x1024"}' \
  -o /tmp/img.json
# вытащить base64 → PNG в outbox (уйдёт пользователю):
python3 -c "import json,base64; d=json.load(open('/tmp/img.json')); \
open('/app/outbox/image.png','wb').write(base64.b64decode(d['data'][0]['b64_json']))"
```
- `size`: `1024x1024` (квадрат), `1536x1024` (гориз.), `1024x1536` (верт.).
- Промпт лучше писать по-английски и подробно (стиль, фон, свет, композиция) —
  качество выше. Переведи описание пользователя сам.

## Грабли (не повторять)
- Не ставь короткий таймаут — генерация НЕ мгновенная, `-m 60` оборвёт её впустую.
- Если пришёл `{"error": …}` вместо `data` — покажи пользователю текст ошибки
  (напр. кончились токены), не пытайся молча ретраить.
- b64 большой (1–3 МБ) — не печатай его в чат, только декодируй в файл.
